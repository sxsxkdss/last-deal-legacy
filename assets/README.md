# assets/

Your asset pack goes here. Empty folders = the built-in look and sounds.

- `cards/L-r-7.png` … card faces
- `sounds/play.ogg` … sound effects (every name and where it plays: `SOUNDS.md`); `sounds/music*.mp3` … a random playlist
- `font/ui.woff2`, `font/display.woff2` … fonts
- `bg.png` … background
- `pack.json` … options

Names, sizes and starting files: `../template/README.md`.
